# Gurukula Tuitions

A premium tuition centre website built using HTML, CSS, and JavaScript. It features a modern, dark-themed interface designed to present academic programs, faculty, campus facilities, and admission information.

## Live Demo

[Visit Gurukula Tuitions](https://premium-tuition.vercel.app/)

## Features

- **Modern UI:** Premium dark-themed design with interactive visual elements.
- **Responsive Layout:** Designed to adapt to different screen sizes.
- **Academic Programs:** Information on eight subjects, including Mathematics, Physics, Chemistry, Biology, Computer Science, Commerce, English, and History.
- **Faculty Showcase:** Dedicated section highlighting educators and their qualifications.
- **Campus Gallery:** Visual presentation of learning spaces and facilities.
- **FAQ Section:** Answers to common questions about classes, learning resources, and admissions.
- **Admission Enquiry:** Quick enquiry form with WhatsApp integration.
- **Interactive Elements:** Animated visuals and interactive website components.

## Tech Stack

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, animations, and responsive design
- **JavaScript** – Interactivity and dynamic behaviour

## Website Sections

1. **Home** – Introduction to Gurukula Tuitions.
2. **About** – Educational philosophy and learning approach.
3. **Subjects** – Overview of eight academic subjects.
4. **Faculty** – Educator profiles and qualifications.
5. **Campus Gallery** – Learning facilities and campus spaces.
6. **FAQs** – Answers to frequently asked questions.
7. **Admissions** – Enquiry form and WhatsApp contact.

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (optional)
- Live Server extension (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/akashprabhu683/lee-rep.git
   ```

2. Navigate to the project directory:

   ```bash
   cd lee-rep
   ```

3. Open `index.html` in your browser.

Alternatively, open the project in VS Code and use Live Server for local development.

## Deployment

The website is deployed on [Vercel](https://vercel.com/).

**Live URL:** https://premium-tuition.vercel.app/
